Build this GitHub workflows:

* `build.yaml` should have four required input parameters: `repo`, `branch`, `workspace`, `imageName`, and one optional `imageTag`. It should clone the external repository, checkout the branch, navigate into `workspaces/$workspace` and run `yarn install` and `npx -y @red-hat-developer-hub/cli@1.10.x plugin package --tag '$imageName:$imageTag`. The job should just run when trigger by `christoph-jerolimov`.
* `bcp-main.yaml` should have just one input parameter, a `workspace`. It should call the build workflow. As repo it should use `https://github.com/backstage/community-plugins` and as branch main. The `workspace` should be passed as `workspace` and, prefixed with `bcp-`, as `imageName`. The workspace input should be checked that its matches a folder name pattern `^[a-zA-Z-]+$`
* `bcp-pr.yaml` should be similar to `bcp-main.yaml` but it should ask for `workspace` and a `pr`. The PR input pattern should be checked (`^[0-9]+$`). Then the workspace should be passed as `workspace` and, prefixed with `bcp-`, as `imageName`. The tag should be passed as `imageTag`.
* `bcp-cron.yaml` should be also similar to `bcp-main.yaml` and start `build.yaml` but runs as cronjob (every day) and starts builds for a list of workspaces: acr, argocd, bookmarks, jfrog-artifactory, multi-source-security-viewer, nexus-repository-manager, npm, ocm, quay, rbac, servicenow, tekton, topology.
* `rhdh-plugins-main.yaml`, `rhdh-plugins-pr.yaml` and `rhdh-plugins-cron.yaml`, similar to the bcp jobs, but for `https://github.com/redhat-developer/rhdh-plugins` and with the `rhdh-` image name prefix. `rhdh-plugins-cron.yaml` for workspaces: adoption-insights, ai-integrations, app-defaults, bulk-import, extensions, global-header, homepage, lightspeed, quickstart, scorecard, theme, translations.
* `proberaum-main.yaml`, `proberaum-pr.yaml` and `proberaum-cron.yaml`, similar to the bcp jobs, but for `https://github.com/proberaum/backstage-plugins` and with the `proberaum-` image name prefix. `proberaum-cron.yaml` for workspaces: analytics-viewer, config-viewer, devtools, env-viewer, github-notifications, hcloud, icon-viewer, permissions-viewer, scheduler-notifications, whats-new.
